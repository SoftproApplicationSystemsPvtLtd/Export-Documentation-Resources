# Export Documentation Checklist

Preparing accurate export documentation is an important part of a smooth international shipment. Exporters may need to prepare several documents containing overlapping information, so consistency and careful verification are essential.

This checklist provides a practical framework for reviewing export documentation before a shipment is processed. Specific documentation requirements can vary depending on the product, destination country, mode of transport, applicable regulations, and terms of sale.

## 1. Basic Shipment Information

Before preparing individual documents, verify the basic details of the transaction.

* Exporter name and address
* Buyer or consignee name and address
* Notify party, where applicable
* Country of origin
* Destination country
* Port of loading
* Port of discharge or destination
* Mode of transport
* Invoice number
* Invoice date
* Purchase order or reference number
* Incoterms, where applicable
* Currency of the transaction

Make sure these details are consistent across the documents where they are required.

## 2. Commercial Invoice Checklist

The commercial invoice is one of the key documents in an export transaction.

Check the following:

* Exporter details are correct
* Buyer details are correct
* Invoice number is unique and accurate
* Invoice date is correct
* Product descriptions are clear
* Quantity and units are correct
* Unit prices are correct
* Total value is calculated correctly
* Currency is clearly stated
* Applicable trade terms are included
* Country of origin information is provided where required
* Payment terms are correct
* Any required declarations are included
* Tax or other applicable information is correctly presented

Particular attention should be given to the relationship between quantity, unit price, and total value.

## 3. Packing List Checklist

The packing list should accurately describe how the goods are physically packed.

Verify:

* Invoice reference
* Exporter and consignee details
* Number of packages
* Package type
* Product description
* Quantity
* Net weight
* Gross weight
* Dimensions, where applicable
* Marks and numbers
* Package-wise details where required

The quantities and descriptions on the packing list should correspond with the commercial invoice and other relevant shipment documents.

## 4. Product Information

Product information should be reviewed carefully before documents are finalized.

Check:

* Product description
* Product code or model number
* Quantity
* Unit of measurement
* Country of origin
* Harmonized System classification, where applicable
* Technical or regulatory information where required
* Product-specific certification requirements

Product descriptions should be sufficiently clear to support customs and logistics processing.

## 5. Shipping Documentation Checklist

Depending on the shipment and transport mode, additional shipping documents may be required.

Review applicable documents such as:

* Shipping Bill or applicable export declaration
* Bill of Lading
* Air Waybill
* Shipping Instructions
* Certificate of Origin
* Inspection Certificate
* Insurance documents
* Transport-related documents
* Export licenses or authorizations, where applicable

The exact documents required depend on the nature of the shipment and applicable rules.

## 6. Cross-Document Verification

One of the most important steps is checking information across documents.

Compare:

| Information         | Commercial Invoice | Packing List     | Shipping Documents |
| ------------------- | ------------------ | ---------------- | ------------------ |
| Exporter            | ✓                  | ✓                | ✓                  |
| Consignee           | ✓                  | ✓                | ✓                  |
| Invoice number      | ✓                  | ✓                | Where applicable   |
| Product description | ✓                  | ✓                | ✓                  |
| Quantity            | ✓                  | ✓                | ✓                  |
| Weight              | Where applicable   | ✓                | ✓                  |
| Package count       | Where applicable   | ✓                | ✓                  |
| Destination         | ✓                  | ✓                | ✓                  |
| Value               | ✓                  | Where applicable | Where applicable   |

Not every field is required on every document, but information that is repeated should be consistent.

## 7. Weight and Package Verification

Weight-related errors can cause unnecessary complications.

Before finalizing documentation:

* Verify net weight
* Verify gross weight
* Confirm package count
* Confirm package dimensions where required
* Check that totals correspond with package-level information
* Confirm units of measurement

Where multiple documents contain weight information, compare them before final submission.

## 8. Regulatory and Compliance Review

Documentation should be reviewed against the requirements applicable to the particular shipment.

Consider:

* Product-specific export restrictions
* Destination-country requirements
* Required licenses or permissions
* Certificates
* Origin requirements
* Customs classification
* Contractual documentation requirements
* Transport requirements
* Buyer-specific documentation requirements

Exporters should verify current requirements with the relevant authorities, customs professionals, logistics providers, or other qualified sources where necessary.

## 9. Electronic Data and Filing Checks

Many export processes involve electronic submission or digitally generated information.

Before submission:

* Confirm that required electronic fields are complete
* Verify that data matches the underlying documents
* Check file formats where applicable
* Review generated files before uploading
* Confirm that required reference numbers are correctly entered
* Keep records of submitted documents and acknowledgements

Automated document generation can reduce repetitive data entry, but generated information should still be reviewed before submission.

## 10. Final Pre-Shipment Review

Before the shipment leaves the facility, conduct a final documentation review.

* [ ] Buyer and consignee details verified
* [ ] Invoice number and date verified
* [ ] Product descriptions checked
* [ ] Quantities checked
* [ ] Unit prices checked
* [ ] Total values checked
* [ ] Currency verified
* [ ] Package count verified
* [ ] Net weight verified
* [ ] Gross weight verified
* [ ] Product classification reviewed where applicable
* [ ] Shipping documents reviewed
* [ ] Required certificates checked
* [ ] Required licenses or permissions checked

* [ ] Copies of final documents retained

## 11. Common Causes of Documentation Errors

Export documentation errors frequently arise from routine administrative issues rather than complex problems.

Common examples include:

* Copying outdated customer information
* Re-entering the same information manually
* Using different product descriptions
* Entering inconsistent quantities
* Incorrect calculations
* Mismatched weights
* Incorrect package counts
* Using an outdated document template
* Failing to update a document after a commercial change
* Not performing a final cross-document review

A standardized workflow can help reduce these risks.

## 12. Improving the Documentation Process

A checklist is useful, but exporters can improve efficiency further by establishing a consistent documentation workflow.

Useful practices include:

1. Maintain standardized document templates.
2. Keep customer and product information organized.
3. Minimize repetitive manual data entry.
4. Use consistent product descriptions.
5. Establish a review process before finalization.
6. Maintain records of completed shipments.
7. Keep document versions organized.
8. Train staff on documentation procedures.
9. Review recurring errors and improve the workflow.
10. Consider specialized export documentation software as shipment volumes increase.

Software can be particularly useful when the same transaction information needs to be used across multiple documents.

## Conclusion

Accurate export documentation requires more than preparing individual forms. The information needs to remain consistent throughout the documentation workflow, and the final documents should be reviewed before submission or shipment processing.

A structured checklist can help exporters identify common errors, standardize their review process, and improve documentation efficiency.
